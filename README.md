# 🎙️ تطبيق مُسَاجَلَة الشعرية الذكي

تطبيق ويب تفاعلي يتيح لعشاق الأدب العربي خوض مساجلات شعرية حية ضد النظام اعتماداً على تقنيات الذكاء الاصطناعي المدمجة للمتصفح.

## 🚀 المميزات الحالية:
- **تحويل الصوت إلى نص (STT):** إلقاء الأبيات الشعرية صوتياً عبر الميكروفون باللغة العربية الفصحى.
- **الرد الفوري والذكي:** يقوم النظام بالرد ببيت يبدأ بحرف روي البيت الملقى، مع تجنب تكرار الأبيات في الجلسة الواحدة.
- **النطق الصوتي التلقائي (TTS):** يقوم النظام بإلقاء الرد صوتياً بلكنة فصيحة ومُشكلة.
- **لوحة تحكم كاملة (Admin Panel):** إمكانية إضافة أبيات جديدة وتعديل المادة وتوسيعها محلياً بكل سهولة.

## 🛠️ التقنيات المستخدمة:
- **الواجهة الأمامية:** HTML5, Tailwind CSS.
- **المنطق البرمجي:** JavaScript (Vanilla JS Module).
- **الذكاء الاصطناعي والمحركات المدمجة:** Web Speech API (SpeechRecognition & SpeechSynthesis).
- **قاعدة البيانات:** تخزين محلي ديناميكي مستمر عبر المتصفح `localStorage`.

## 📂 طريقة التشغيل محلياً:
فقط قم بتحميل الملفات، وافتح ملف `index.html` على متصفح **Google Chrome** أو **Microsoft Edge**.
